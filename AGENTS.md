# Repository Guidelines

## Структура проєкту
- Вхідна точка: `index.html` (однофайловий застосунок).
- Статика: `static/`
  - Скрипти: `static/scripts/script.js`
  - Стилі: `static/styles/style.css`
  - Зображення: `static/img/`
- Призначення: вертикальна лінійка для навігації та трекінгу плетення силянки; крок калібрується під масштаб картинки, підтримується офсет і збереження у проєктах.

## Запуск і розробка
- Білд відсутній. Запуск локально:
  - `python3 -m http.server 8080` і відкрийте `http://localhost:8080/index.html`.
  - Або просто відкрийте `index.html` у браузері.
- Лінт/форматери не налаштовані — дотримуйтеся стилю нижче.

## Стиль коду та наймінг
- Технології: HTML, vanilla JS, CSS. Відступ — 2 пробіли.
- Імена файлів/папок — нижній регістр, прості назви (`script.js`, `style.css`).
- JS: дрібні функції, уникайте глобальних витоків; логіку тримати у `static/scripts/script.js`.
- CSS: розширюйте `static/styles/style.css`, використовуйте класи, уникайте inline‑стилів.

## Тестування
- Фреймворки відсутні — перевіряйте вручну в Chrome/Firefox/Safari та на мобільних.
- Перевірити ключові сценарії: завантаження зображення/PDF, перетягування лінійки, калібровка (start/end), офсет (🎯), крок (px), навігація ◀/▶, прилипання до сітки, збереження/оновлення/видалення проєкту, відновлення зі `localStorage` (`beadProjects`).
- Перевірити тач/жести: відсутність pinch‑zoom, коректні drag події, роботу на малих екранах.

## Коміти та Pull Requests
- Історія лаконічна (наприклад, "fix", "improve"). Рекомендовано короткі, імперативні заголовки: `fix: calibration end state`, `feat: row offset`.
- PR має містити: опис змін і мотивацію, скріншоти/гіфи UI, кроки ручного тесту та перелік браузерів/пристроїв.

## Поради для агентів/автоматизації
- Не додавайте менеджери пакетів, бандлери чи серверні фреймворки.
- Змінюйте лише `index.html`, `static/scripts/script.js`, `static/styles/style.css` (та пов’язані ресурси), якщо не погоджено інше.
- Підтримуйте існуючі CDN‑залежності (Toastify, pdf.js, SweetAlert) і сумісність браузерів.

## Дані та безпека
- Дані проєктів зберігаються у `localStorage` під ключем `beadProjects` (зображення можуть бути як data URL). Обробляйте помилки квоти та уникайте зберігання чутливих даних.
